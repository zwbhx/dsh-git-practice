dsh-git-practice

GitHub 常态化学习的练习仓库 · 由 GitHub Pages 托管（本页即 Pages 产物）

这个仓库是干什么的

  • 练习 Conventional Commits：提交信息由 scripts/commit_lint.py 校验
  • 练习 Issue → 分支 → PR → review → 合并 → tag/release 的闭环
  • 练习 GitHub Actions：CI 跑语法检查 + 21 个单元测试 + 提交信息检查
  • 练习 分支保护：main 必须走 PR、必须状态检查通过、禁止 force push

你正在看的这一页证明了什么

  • Pages 已启用，且能从 main 分支根目录构建静态站点
  • 本文件 index.html 与 .github/CODEOWNERS 是通过 PR 合入的，而不是直接 push 到 main —— 因为 main 已被分支保护

本地等价命令

  • python -m unittest discover -s tests -v —— 21 个测试
  • python scripts/commit_lint.py "feat(cli): 新增参数" —— 校验提交信息
  • python scripts/weekly_checklist.py --month —— 生成周例行清单
